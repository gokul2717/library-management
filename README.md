# 📚 Central Library

A simple college library website to browse, search, add, and delete books.

## 🚀 Features

- Browse all books as cards
- Search by name, author, category, or language
- Click a book to see full details
- Admin can add books
- Admin can delete books

## 🛠 Built With

- HTML5, CSS3, Bootstrap 5
- JavaScript
- PHP (PDO)
- MySQL

## 📁 Folder Structure

library/
├── library.html
└── backend/
    ├── config/db.php
    ├── api/books.php
    ├── api/book.php
    ├── api/search.php
    └── schema.sql
